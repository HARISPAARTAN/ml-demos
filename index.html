Six small ML demos, each with the maths behind it

Every demo runs entirely client-side: the retrieval, the attention weights, the optimiser steps and the clustering are computed in JavaScript as you interact. Each one has its own page with the demo on the left and the theory on the right.

How it is built

  • Plain HTML, CSS and JavaScript, no framework and no build step for the demos themselves; the pages are generated from one template by a small Python script.
  • Each demo is one self-contained module in js/demos/ that draws into its page and returns a cleanup function.
  • Formulas are typeset with a self-hosted copy of KaTeX; fonts are self-hosted too, so no request leaves the page.
  • Light and dark theme, keyboard focus styles and reduced-motion support shared with my portfolio.
